# Employee Salary Analyzer

A Python-based command-line application for analyzing employee salary data.

## Features
- Read employee salary data from a text file
- Calculate total salary
- Find the highest-paid employee
- Filter employees based on salary threshold
- Display employee information
- Handle invalid user input
- Menu-driven command-line interface

## Technologies Used
- Python 3
- File Handling
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run
1. Clone the repository
2. Open the project folder in VS Code
3. Make sure `employee_analyzer.py` and `employees.txt` are in the same folder
4. Run the following command:


python employee_analyzer.py


##Example
The application provides a menu-driven interface:


Employee Salary Analyzer
1. Show employees
2. Show total salary
3. Show highest paid
4. Show employees above threshold
5. Exit

Enter an option from 1-5: 2
Total salary: 245000

Enter an option from 1-5: 3
Highest paid employee: {'name': 'Sneha', 'salary': 80000}
